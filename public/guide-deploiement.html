Avant de commencerPréparez le kit du site (5 minutes)

  1. Téléchargez le kit du site : ouvrez le panneau d'administration du site (bouton ⚙ / 🔐 dans le pied de page), puis cliquez sur ⬇️ Kit du site (.zip) — ou directement ici : ⬇️ Télécharger le kit (.zip)
  2. Ouvrez le fichier téléchargé, faites un clic droit → Extraire tout… → Extraire. Vous obtenez un dossier (ex. mosquee-site-source). Laissez ce dossier ouvert.
💡 Le kit contient tout le site, sans vos clés secrètes (c'est voulu : vous les collerez vous-même en toute sécurité à l'étape 3).
1

GitHub — déposer les fichiers≈ 10 minutes · site : github.com

  1. Allez sur github.com et cliquez sur Sign up (créer un compte). Entrez votre e-mail, un mot de passe, un nom d'utilisateur (ex. mosquee-hadja). Notez-les !
  2. GitHub envoie un code de vérification par e-mail → recopiez-le sur le site.
  3. Une fois connecté, en haut à droite cliquez sur le + puis New repository.
  4. Remplissez ainsi : Nom du dépôt : mosquee · Choisissez Public · Ne touchez à rien d'autre · Cliquez sur Create repository.
  5. Sur la page qui s'affiche, cliquez sur le lien « uploading an existing file » (téléverser un fichier existant).
  6. Ouvrez votre dossier extrait, sélectionnez TOUT son contenu (Ctrl+A), puis glissez-déposez tout au milieu de la page GitHub. Attendez la fin de l'envoi (la barre doit être pleine).
  7. Cliquez sur le gros bouton vert Commit changes. C'est fini pour GitHub ✅
⚠️ Si le dossier contient un fichier .env ou un dossier db, ne les téléversez pas (le kit n'en contient normalement pas — c'est une protection).
2

Neon — créer la mémoire≈ 5 minutes · site : neon.tech

  1. Allez sur neon.tech et cliquez sur Sign up. Choisissez Continue with GitHub (le plus simple : votre compte GitHub sert de clé).
  2. Une fois connecté, cliquez sur Create project (ou New project).
  3. Nom du projet : mosquee · laissez les autres choix par défaut · cliquez Create.
  4. Neon affiche une chaîne de connexion qui commence par postgresql://… (dans « Connection Details » ou « Connection string »).
  5. Cliquez sur l'icône copier 📋 à côté de cette chaîne, puis collez-la dans un fichier texte ou une note sur votre téléphone/ordinateur. On l'utilise à l'étape 3.
💡 Cette chaîne ressemble à : postgresql://utilisateur:motdepasse@ep-xxxx.eu-central-1.aws.neon.tech/neondb?sslmode=require — c'est secret, comme une clé de maison : ne l'envoyez à personne.
3

Vercel — allumer le site≈ 15 minutes · site : vercel.com

  1. Allez sur vercel.com et cliquez sur Sign Up → choisissez Continue with GitHub → autorisez Vercel.
  2. Cliquez sur Add New… → Project.
  3. Dans la liste, trouvez mosquee et cliquez sur Import.
  4. AVANT de cliquer sur Deploy : sur la même page, ouvrez la section Environment Variables (Variables d'environnement). Vous allez ajouter 5 lignes : pour chacune, collez le Name puis la Value, puis cliquez Add.
Name (nom)Value (valeur)
DATABASE_URL La chaîne postgresql://… copiée à l'étape 2
PAYTECH_API_KEY Votre clé API PayTech (fournie dans le message qui accompagne ce guide)
PAYTECH_API_SECRET Votre clé secrète PayTech (même message)
PAYTECH_ENV test  (pour les paiements d'essai — on passera à prod plus tard)
ADMIN_PASSWORD Votre mot de passe administrateur (même message)
  1. Maintenant cliquez sur Deploy et attendez 2 à 3 minutes (des messages défilent, c'est normal).
  2. Quand l'écran affiche une confettis/félicitations 🎉, cliquez sur Continue to Dashboard puis sur Visit : votre site est en ligne !
💡 Vercel crée et remplit automatiquement la base de données (vos 6 événements y seront déjà). Les prochains changements se feront directement dans le panneau ⚙ Administration du site en ligne — plus besoin de re-télécharger de fichier !
✔

Vérifier que tout fonctionne2 minutes

  • La page d'accueil s'affiche avec les images.
  • L'onglet Événements montre vos événements.
  • Le bouton Faire un don ouvre la page de paiement PayTech.
  • Le panneau ⚙ Administration s'ouvre avec votre mot de passe.
  • En cas de souci : onglet Deployments sur Vercel → cliquez ⋯ → Redeploy.
🌐

Optionnel — remettre votre domainemosque.billgatenadir.com

  1. Dans Vercel : votre projet → Settings → Domains → Add → tapez mosque.billgatenadir.com.
  2. Vercel affiche 1 ou 2 lignes DNS à copier (une adresse A ou CNAME).
  3. Chez votre hébergeur actuel (là où le domaine est géré), remplacez les anciens DNS par ceux donnés par Vercel.
  4. Attendez de 15 minutes à quelques heures — Vercel installe le HTTPS automatiquement. 🎉
⚠️ Cette étape se fait après que le site fonctionne sur l'adresse .vercel.app. Si votre hébergeur actuel a un tableau de bord compliqué, dites-le-moi et je vous guiderai écran par écran.
🔒

Sécurité de vos clésÀ lire absolument

  • Les clés PayTech et le mot de passe admin vivent uniquement dans les Environment Variables de Vercel — jamais dans le code, jamais sur GitHub.
  • Le kit .zip que vous téléchargez ne contient aucune clé : vous pouvez le partager sans risque.
  • Ne copiez jamais les clés dans un message WhatsApp, un e-mail ou un fichier Word.
  • Si vous soupçonnez une fuite : changez le mot de passe admin (Vercel → Settings → Environment Variables → Redeploy).
